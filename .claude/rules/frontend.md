# Frontend rules

- `next.config.mjs` sets `agentRules: false` on purpose. Leave it. Without
  it every `next dev` writes `frontend/CLAUDE.md`, a second instruction
  source competing with the root one.
- `frontend/public/sw.js` is generated by `scripts/build-sw.mjs` from
  `sw/sw.template.js` after every build and is gitignored. Edit the template.
  `scripts/fix-export-segments.mjs` repairs the static export's RSC segment
  paths that Next 16.4 writes wrongly on Windows; keep it in `build:mobile`.
- `npm run lint` exits 1 on 4 errors + 1 warning that are deliberately left:
  `react-hooks/set-state-in-effect` in `useGeminiApiKey.ts` and
  `UploadForm.tsx` (the read-localStorage-after-hydration pattern a static
  export needs) and `@next/next/no-img-element` in `ResultsView.tsx`. Do not
  silence the rule or rewrite those effects; that is the owner's call. Do not
  add new findings. `eslint.config.mjs` ignores `android/**` and
  `public/sw.js` (generated) and turns `no-html-link-for-pages` off for
  `app/offline/**` only, where plain `<a>` is required offline.
- Every route is prerendered and the Capacitor build is `output: "export"`.
  Tabs are a query param (`/app?view=…`), never route folders. Nothing may
  read `localStorage` during render; shell mode and theme are stamped on
  `<html>` by the pre-paint scripts in `app/layout.tsx`.
- Both shells (`web` top nav, `app` bottom tab bar + More sheet) are always
  rendered and CSS hides one; never choose chrome in React state.
- New tab: add the id to `MAIN_TABS` (`application/useMainTab.ts`), a label
  to `TAB_LABEL` (`components/AppNav.tsx`), a `MoreSheet.tsx` row if the
  installed shell should reach it, and a `.tab-view` section in
  `HomeScreen.tsx`.
- Hooks go in `application/`, adapters in `infrastructure/` behind a port in
  `domain/ports.ts`, registered once in `infrastructure/container.ts`.
  Components never call an adapter directly. Capacitor-only adapters are
  no-ops when `Capacitor.isNativePlatform()` is false.
- Visual system: `docs/frontend/design-direction-editorial.md`. Read it
  before UI work; the Terminal doc it supersedes is history only.
- Android: `versionName` comes from `package.json`; bump there for a release.
  `versionCode` is supplied by CI as the commit count and must never
  decrease. `android/debug.keystore` is checked in on purpose so every debug
  APK signs with one identity. Local `npm run android:sync` and Gradle builds
  are fine on a developer machine, never in a cloud session, and a local APK
  is never shipped.
